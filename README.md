# TezAqsha

[TezAqsha](https://tezaqsha.com/) — независимый информационный сервис сравнения микрокредитов и проверки финансовых сервисов Казахстана. Сайт не является банком или микрофинансовой организацией, не принимает заявки и не принимает платежи.

## Языковые версии

- [Русская версия](https://tezaqsha.com/)
- [Қазақша нұсқа](https://tezaqsha.com/kk)

## Как проверяются сведения

Приоритет отдается государственным реестрам и документам регулятора, затем официальным документам самой организации. Неподтвержденные ставки, лицензии, отзывы и обещания одобрения не публикуются как факты.
