# Сообщить об исправлении

Создайте Issue и приложите:

1. Точный URL страницы TezAqsha.
2. Фрагмент, который нужно проверить.
3. Ссылку на государственный реестр, официальный документ или официальный сайт организации.
4. Дату, когда источник был доступен.

Не отправляйте ИИН, данные карты, SMS-коды, номер договора, банковскую выписку или иные персональные данные. GitHub Issues публичны.
